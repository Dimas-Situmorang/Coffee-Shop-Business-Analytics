# Project Scope — Coffee Shop BI Dashboard

## Fokus

Project ini adalah project Data Analyst / Business Intelligence. Fokusnya adalah mengubah data transaksi coffee shop menjadi dashboard interaktif yang mudah dipahami owner bisnis.

## Tidak Termasuk

- Machine learning
- Forecasting
- Inventory recommendation
- Model deployment

Bagian tersebut dipisahkan ke project kedua agar portfolio tidak terlihat campur aduk.

## Pertanyaan Bisnis

Dashboard ini menjawab:

1. Bagaimana tren revenue dari bulan ke bulan?
2. Kategori produk apa yang menjadi revenue driver?
3. Produk mana yang paling berkontribusi?
4. Cabang mana yang paling kuat?
5. Jam dan hari apa yang paling ramai?
6. Keputusan bisnis apa yang bisa diambil owner?

## Target User

- Owner coffee shop
- Manajer operasional F&B
- Business analyst
- Data analyst portfolio reviewer

## Output

- Dashboard interaktif berbasis web
- KPI cards
- Grafik tren dan ranking
- Heatmap jam ramai
- Insight dan rekomendasi keputusan bisnis
